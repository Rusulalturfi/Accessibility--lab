# Accessibility--lab
Reflection Questions

What accessibility enhancements were the most challenging to implement, and why?
The most challenging part for me was understanding how to fix accessibility issues on a webpage. The video showed issues such as missing form labels, missing image alternative text, and poor text contrast. I learned that labels should be connected to form inputs, images need useful alternative text, and text needs enough contrast with its background.


How do ARIA attributes improve the experience for users relying on assistive technologies?
ARIA attributes provide extra information about elements on a webpage. Screen readers can use this information to describe controls, instructions, and messages to users. ARIA can help when semantic HTML does not provide enough information.

What tools did you use to check color contrast, and how did they help?
I used WebAIM’s Contrast Checker to test the contrast between text and background colors. My first color combination had a contrast ratio of 2.6:1 and did not pass. After I changed the background color to #F8E7E7, the ratio increased to 9.37:1 and passed. This helped me choose colors that make text easier to read.
